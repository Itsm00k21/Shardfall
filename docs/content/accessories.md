# Accessories

G-006. Twenty accessories for the ring, amulet, and charm slots, for a later catalog draft and the 3D art pass.

Slots match `Schema.ACCESSORY_SLOTS`: `ring`, `amulet`, `charm`. `ItemBases.luau` has no Accessory kind yet. Each row is one suggested stat, using an id from `Stats.DEFS`. The number is a suggestion, not a live range. One stat keeps a future row easy to paste. These are earned loot. They are not a Robux product, and they do not change drop odds or raid power.

Left unused on purpose: `verdant_ring` (Root Mole combo id in `Pets.luau`) and `capture_charm` (WildCapture charm, no combat stat, 250 gold).
