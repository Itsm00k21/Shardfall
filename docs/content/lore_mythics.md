# Mythic Codex lines

G-021. One Codex line for every Mythic weapon, armor piece, accessory, and pet already named in `docs/content/`.

A page is text for a later item Codex. It is not one of the ten mechanic keys in `Codex.luau`, and this file does not edit that module. Owning the gear, or hatching the pet, is the suggested unlock. The page pays nothing. A paid skip is refused. Nothing here is a live drop.

Choice: a Mythic title or a pass skin is not an item, so those names are listed under Left out and do not get a page.
