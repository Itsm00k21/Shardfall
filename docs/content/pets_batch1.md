# Pets batch 1

G-003. Twenty new companions across all six rarities, for a later pet catalog and the 3D art pass.

Checked against `Pets.luau`, `PetEvolution.luau`, `ItemBases.luau`, and `docs/design/shardfall_pets.md`. These are not the beta eight, the catalog pets, the wild-capture forms, or the evolution forms. Evolution lines stay in G-004. Each row is one suggested passive for the Active Fighter. Percents are suggestions, not live numbers. Pets are not sold for Robux.

Personality is the hatch default from the set in `Pets.luau`: Brave, Playful, Lazy, Curious, Grumpy, Loyal.
