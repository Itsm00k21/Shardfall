`BannerFit.fit(viewportX, viewportY, textScale)` returns a new rect `{ x, y, w, h, textSize }`. The viewport is already the safe area. Text size is `max(UiTheme.MIN_TEXT, floor(16 * scale + 0.5))`. A missing or bad scale is 1, so the size stays 16. The rect stays inside that viewport. Height is the line, and the bottom stops at the top of `HudLayout.toast`. Extra arguments are ignored, so `paid`, a product id, Robux, `cost`, and `skip` do not move the rect.

`ShardfallBanner` sets `IgnoreGuiInset` false and `ScreenInsets` to `CoreUISafeInsets`. `showBanner` and `setProfile` apply the fit. The words, the gold, error, and ok colors, and `ShellLayout.BANNER_SECONDS` are unchanged.

## Questions for Ghost

These are non-blocking. The defaults below are what the code does.

1. The banner gui uses `ScreenInsets.CoreUISafeInsets` and `IgnoreGuiInset = false`, the same pair as `HudShell`. `BannerFit` then treats that gui's box as the safe viewport and insets `UiTheme.PAD` (8) on every side. Default: keep both properties. Say if the banner should only flip `IgnoreGuiInset` and stay on the topbar inset.
2. The line is `textSize + 16`. Scale 1 is 16px text in a 32px bar. Scale 1.4 is 22px text in a 38px bar. The label's existing padding is 8 on the top and the bottom. A line taller than the gap above `HudLayout.toast` (`UiTheme.safeMargin()`, the same margin `HudShell` passes) is shortened so the bottom stops on the toast's top edge. The font stays on the formula. Default: one line, clamp the height, do not shrink the font. Say if the old 56px bar should stay.
3. The bar is inset 8px from the left, right, and top of the safe viewport. It is not the old 92% width. Default: keep the 8px inset. Say if it should stay 92% and centered.
4. Hide-when-empty was already on `cursor/live-build-9721`. `banner.Visible = text ~= ""` has been there since `e3e1438`. No newer hide landed on that branch (no banner commit from bc-27ddc3a2). I kept that line. A nil text is not `""`, so `nil ~= ""` still counts as visible, and a whitespace-only string still shows. Default: keep the landed check. Say if nil and whitespace should hide too. Kevin's empty yellow bar may be one of those.
5. `fit` does not read a fourth argument. A table passed in the scale slot is a bad scale, so the size stays 16 and the rect matches scale 1. Default: `paid`, `productId`, `robux`, `cost`, and `skip` never move the rect, including `robux = 0`, `cost = 0`, and `skip = false`.
6. `setProfile` reads `uiSettings.access.textScale` on every profile. A missing access table drops the scale back to 16. The fit also runs when the banner shows, and when `AbsoluteSize` or the camera viewport changes. Until `AbsoluteSize` is at least 200 on both axes, the fit uses `MobileShell.view` of the legacy screen. Default: keep those call sites and that first-frame fallback.
7. No build stamp. `Build.luau`, both init prints, and the `DungeonService` print were not edited. Default: Ghost stamps on merge. The printed line stays `3ddf279+`.
