# T-087 hooks for GHOST

`RollNear` is pure display. It does not roll, and it does not change a rarity or the odds. A paid roll and a free roll take the same path. Nothing in `src` requires it yet.

`note(state, roll)` is the screen call. `near(roll)` judges a land without moving the streak. `streak(state, landed)` only moves the count. Store `state` only when `ok == true`. Each call returns a new table.

```lua
local opened = RollNear.fresh()
-- opened.state.streak == 0

local noted = RollNear.note(state, {
	rarity = landedRarity, -- the rarity the server actually returned
	watched = nil, -- a Rarities.ORDER name, or nil when nothing is watched
	counter = sinceLegendary,
	goal = legendaryGoal,
	pity = "Legendary",
	paid = paid, -- accepted and ignored
	landed = true,
})
```

Show `noted.rarity`. If `noted.nearMiss` then play one close-call beat. `watchedStep` and `pityShort` say which rule fired. Do not put either flag into the reel as another item. A miss is `landed = false`: the streak becomes 0 and the result has no rarity.

Suggested call site: the Roll tab in `MenuHub.luau`, after the server result is in, beside the existing `RollHype.note`. Do not call this from `RollMath` or `RollService`. Do not edit `RollHype.luau`. Do not bump Schema. This streak is not a profile field.

## Questions

1. Which pity triple does the Roll screen pass? The live legendary guarantee is profile `sinceLegendary` against `RarityConfig.LEGENDARY_PITY` (1000). Epic is `sinceEpic` / `EPIC_PITY` (100). Pool `pityLegendaryAt` (50) is a different counter, and T-069 says the crack path does not use it. This module takes one counter, one goal, and one pity rarity per call.
2. Is that counter the value before this roll, or the value after `RarityConfig.advance`? One short means `counter + 1 == goal`. A post-roll legendary counter of 999 is one short of 1000. A pre-roll counter of 998 is not.
3. What is the watched rarity? `MenuHub`'s `stopAt` stays `"Off"` until the player picks a stop. `"Off"` is not on `Rarities.ORDER`. Pass `nil` when nothing is watched. An unknown name is refused and the streak does not move.
4. `UiRouter.honestSlots` still drops filler above the rolled rarity and does not add a near-miss. Should the close-call beat stay a flag beside the real card, with the reel's last slot still the item that was rolled?
5. `RollHype.note` already advances a session streak with the same miss/land rule, and `MenuHub` paints `hype.streak`. Should the screen keep that number and call `RollNear` only for the flag, or paint `RollNear`'s streak instead? Callouts at 10, 25, 50, and 100 stay on `RollHype`. This module does not emit them.
6. When `watchedStep` and `pityShort` are both true, `nearMiss` is one flag. Should the screen play one beat or two?
7. Does the Forge trait reroll call this, or only the shard Roll tab? A trait reroll has no ladder land unless the screen maps one.
8. The streak lives only in the table the caller passes back. Should it reset when the Roll tab closes or the chain stops, or only when a roll does not land? This module does not read the tab.
