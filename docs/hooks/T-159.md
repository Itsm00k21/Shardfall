- A finite number returns that number plus 1. `0` returns `1`. `1` returns `2`.
- `nil`, a string, a boolean, NaN, and infinity return `1`.
- A third argument, including `paid = true`, does not change the token.
- Each call reads its arguments and does not write them. No clock. No RNG. No services. The module does not keep the last token.

- A third argument, including `paid = true`, does not make a mismatch hold and does not block a match.
